# 사용 가이드

[$game-design-for-immersion](../.agents/skills/game-design-for-immersion/SKILL.md)는 플레이어 경험을 난이도·감정·콘텐츠·성장 구조와 연결하는 지식 스킬입니다. [README](../README.md)만으로 첫 요청을 실행할 수 있습니다.

## 지식 자료의 역할

원서 4장(`ch01`–`ch04`)은 전체 관점, 상세 18절(`s01`–`s18`)은 특정 기법·조건·사례를 다룹니다. [참조 색인](../.agents/skills/game-design-for-immersion/references/index.md)은 질문을 실제 파일로 연결하고, [목차 대응](../.agents/skills/game-design-for-immersion/references/coverage.md)은 원서 79개 세부 목차의 위치를 찾습니다.

설계 양식은 [실무 패턴](../.agents/skills/game-design-for-immersion/patterns.md), 초안 확인은 [판단표](../.agents/skills/game-design-for-immersion/cheatsheet.md), 용어는 [핵심](../.agents/skills/game-design-for-immersion/glossary.md)·[확장](../.agents/skills/game-design-for-immersion/references/glossary-extended.md) 사전을 읽습니다. 같은 질문이라도 목표 경험과 확정 정책에 따라 적용안은 달라집니다.

## 결과를 읽는 기준

책의 설명에는 장·절·쪽 근거가, 새 제안에는 가정과 검증 방법이 필요합니다. 미정 정책의 빈칸을 확정 사양처럼 채웠거나 실제 읽지 않은 자료를 근거로 제시했다면 후속 요청으로 바로잡습니다. 이 가이드의 예시와 검토 양식은 새 응용 자료입니다.

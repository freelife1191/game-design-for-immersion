# skill-creator 리뷰와 references 심층 검수

2026-10-14 검토를 완료했다. 원서 4장·18절·79개 세부 목차를 기법·적용 조건·예외·대조 사례의 수준에서 검토하고, **19개 세부 절을 보강**했다. 현재 후보는 독립 내용 검토와 최종 정적 검사를 통과했으며, 필수 수정 사항은 없다.

## 스킬 구조

- 넓은 설계는 장 자료에서, 특정 기법·사례·수치는 상세 자료에서 시작하도록 읽기 지시를 정리했다. 사용자가 지정한 읽기 범위는 유지한다.
- 9개의 중복된 장별 요약을 4개의 판단 원칙으로 압축했다. 상세 지식은 기존 장·참조에 남겼다. 진입점 본문은 추정 1,978 → 1,548토큰으로 약 22% 줄었다. 실제 모델 청구 토큰 측정은 아니다.
- UI 기본 요청을 한 문장으로 다듬고 자동 호출 기본값은 유지했다. 새로운 도구·스크립트·자산 의존성은 추가하지 않았다.
- 큰 전략·심리 참조에 원서 절별 바로가기와 명시 앵커를 추가했다. 일반 학습 자료와 출처·검수 JSON의 읽기 목적을 구분했다.
- 오래된 검수 JSON은 출처·기존 문서의 호출처를 확인해 보존했다. 새 로그는 프로젝트 검수 폴더에만 기록했다. [구조 판단](structure-decisions.json)에 부분 수용·유지 이유가 있다.

가용성 편향은 책의 승패·대기 설명과 [APA 일반 정의](https://dictionary.apa.org/availability-heuristic)를 구분했다. 착각적 사고는 [착각적 상관](https://dictionary.apa.org/illusory-correlation)과 [통제의 환상](https://dictionary.apa.org/illusion-of-control)을 묶는 원문 용어로 정리하고 정상적인 통제감과 혼동하지 않도록 보완했다. [용어 검토 기록](terminology-review/review.md)에 실제 원문 쪽과 공식 출처가 있다.

원문 대조 행렬은 [79개 절 점검](depth-coverage.json)과 `source-review/ch01`–`ch04`에 보존했다. 393개 주제는 이 감사에서 나눈 점검 항목이며, 책의 공식 원칙 개수는 아니다. 모든 게임 사례·문장을 옮기는 대신 새로운 판단 조건을 주는 내용의 누락을 보완했다.

시험은 새 컨텍스트에서 후보의 지식 Markdown만 읽어 수행했다. 실제 읽은 파일의 존재·범위·SHA-256은 [읽기 증거](behavior-tests/read-proofs.json)에 있다. PDF·검수 JSON·이전 답변·예상 답안은 수행자에게 제공하지 않았다.

첫 경제 답변은 ‘외형만 유료’를 외형 가격·할인까지 자동 금지하는 범위로 넓혀 실패했다. 이를 그대로 보존하고, 확정 정책의 판매 대상·플레이 효과와 가격·혜택 조건을 나눠 읽는 짧은 지침으로 보완했다. 같은 실제 요청을 새로운 컨텍스트에서 재시험해 통과했다. 특정 게임의 할인을 허용하거나 금지하는 범용 상품 정책은 추가하지 않았다. [첫 판정](final-review/behavior-review.md)과 [최초 실패 기록](behavior-tests/economy-first-verdict.json)을 보존했다.

strategy·psychology·experience는 r1에서 생성된 내용 시험이며 r2 실행·해시 증거로 소급하지 않았다. 최종 후보의 새 경제 시험은 r2에서 수행했다. 서열 위치의 시간 조건은 원문 검수로 보강했지만 심리 시험의 실제 요청에 없었으므로 행동 시험 통과 항목에 포함하지 않았다.

## 변경 범위와 한계

지식·UI·문서 파일 21개를 보완했다. [전체 diff](changes-final.diff), [파일별 변경](changes-final.json), [최종 후보](candidate-manifest-r2.json)를 남겼다. 새로운 스킬 리소스는 추가하지 않았다. 기본 Python 3.15에 검증 패키지가 없어 기존 Python 3.14.8 환경으로 검사를 실행했으며 새 패키지·전역 설정을 설치하거나 변경하지 않았다.

수치 참조, 79개 목차 대응, 과거 검수 JSON, 고급 활용 가이드는 바이트가 동일하다. 고급 활용의 요청 ID 61개·명시 앵커 85개·원래 예시 조건도 유지했다.

이 검수는 모든 원문 문장·사진·도판의 복제나 전수 검증이 아니다. 일부 긴 수식·VIP 표의 OCR/인쇄 혼선은 기존 한계를 유지했다. 심리 연구의 현대 재현성·현행 시장·가격·실제 플레이 성과, 실제 UI 발견·자동 호출·새 호스트 CLI 호출·게임 런타임은 별도 검증 범위다. 이전 후속 FLOW·호스트 통과를 현재 버전 증거로 재사용하지 않았다.

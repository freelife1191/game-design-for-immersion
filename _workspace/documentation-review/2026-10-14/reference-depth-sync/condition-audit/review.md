## 범위와 보존 확인

- 기준 스냅샷과 현재 파일은 동일하다. `README.md` SHA-256은 `1ec108…bf6fc`, `docs/advanced-usage.md` SHA-256은 `df9361…acca`다.
- `before-prompts.json`의 61개 ID가 모두 현재 고급 가이드의 블록으로 존재한다. 현재 요청 ID는 61개, 명시 앵커는 85개이며 각각 중복이 없다.
- 따라서 아래는 이미 존재하는 ID·앵커·가상 입력·확정/미정·숫자를 바꾸지 않는 **문구 보완 제안**이다. `별도 보완 예시`도 새 요청 ID나 앵커를 요구하지 않는 짧은 안내/예시 문단을 뜻한다.
- 심층 보강 보고서가 지적한 19개 절은 [이전 심층 보고서](../../../../skill-creator-review/2026-10-14/reference-depth/report.md)의 “참조의 중요한 보강” 표를 기준으로 삼았다. 이 검토는 실제 게임·호스트 실행 시험이 아니다.

| 4.2.3 획득 난이도 | 낮은 효율이어도 보상이 확실하고 영구적이며 대체 불가능하면 선택될 수 있으므로 시간 효율만으로 제거하지 않는다(`s12-value-system.md` 21행; 본문 240 / PDF 256). | `s12-b`는 획득 시간·대체 가능성·기회비용을 비교하지만 영구성은 빠져 있다. | **부분 반영.** `s12-b`의 산출물 열을 “획득 시간 / 영구성 / 대체 가능성 / 기회비용”으로 바꾸고, 확인 문장에 “낮은 시간 효율을 곧바로 실패로 분류하지 말고 영구·대체 불가능 여부를 확인한다.”를 더한다. |

| 4.4.4 호혜 | 입장권 협력은 고레벨에게 부족한 입장 기회와 저레벨에게 필요한 클리어 도움처럼 양쪽 필요가 교차해야 하며, 공유 사실만으로 지속되지 않는다(`s14-trade-social.md` 28행; 본문 255 / PDF 271). | `s14-b`는 신규·숙련자의 변화와 공동 목표를 두지만 숙련자가 실제로 필요로 하는 자원/기회는 묻지 않는다. | **부분 반영.** `s14-b` 산출물의 `도움 행동`을 “신규가 얻는 도움 / 숙련자가 얻는 입장 기회·자원 / 교차 필요”로 풀고, 확인 문장에 “입장권·보상 공유만으로 호혜 지속을 가정하지 않는다.”를 추가한다. |
| 4.6.3 고과금 유저와 진행 | 결제 우위를 약화하면 중간 결제층 효용이 사라져 비과금·고과금만 남을 수 있으며 충분한 인구·고과금 수요가 조건이다. 공정성/수익의 자동 개선으로 일반화하지 않는다(`s16-paid-content.md` 18행; 본문 266–267 / PDF 282–283). | `s16-b`는 원문 집단별 진행을 역사 사례로 정리하고, `s16-followup`은 진행 격차·동행 단절을 본다. 소비 집단 분포·필요 인구는 없다. | **부분 반영.** `s16-followup` 산출물에 “결제 효용 변화 / 중간 결제층 분포 가설 / 필요한 활성 인구·수요 / 실제 데이터 공백”을 조건부 열로 추가하고, “전투력 판매 없음만으로 이 조건이 자동 적용되지는 않는다.”를 확인 문장으로 둔다. |
| 4.6.5 구체적 결제 금액·분석 | 등급 내 완결감은 구매가 아니라 그 등급에서 유지되는 진행 경험이며, 구매 한도·진행 속도·실제 일일 시간을 함께 대조해야 한다. VIP/가격은 당시 사례다(`s16-paid-content.md` 16, 20행; 본문 270–272 / PDF 286–288). | `s16-b`는 현재 가격·진행 속도·구매 한도를 미정으로 보존하지만 이 세 값과 일일 시간의 관계를 산출하지 않는다. | **부분 반영.** `s16-b` 산출물에 “등급/구매 한도/그로 인한 진행 속도/실제 일일 소요 시간/미정 값”의 관계표를 추가하고, 확인 문장에 “등급 도입·가격·구매 압박을 새 기본 정책으로 확정하지 않는다.”를 넣는다. |

## 미시험 범위와 충돌 점검

- 본 감사는 문서 텍스트와 실제 참조 파일의 대조다. 제안 문장을 반영한 뒤 61개 프롬프트를 실행하거나 실제 플레이테스트를 했다는 증거는 아니다.
- 2.2.5·2.2.6은 심리 효과를 보장하거나 결제 압박을 설계하라는 지시가 아니다. 현재 문서의 가격·보상·확률 고정, 실제 관측, 거절/정보 공개 경계와 함께 써야 한다.

- 1.2.6의 20분, 4.2.3의 0.1%, 4.6의 RMB/VIP·일수는 원서 사례·설명용 조건이다. 제안은 이 숫자를 유지하거나 새 숫자를 넣지 않는다.

# reference-depth-sync 대표 연계 시험 독립 판정

검토일: 2026-10-14  
범위: `trials/noncombat`, `trials/reentry`, `trials/reciprocity`의 역사 시험과 `trials/reentry-r2`의 현재 문구 시험. 실제 요청, 초기 답변, 선택 기록, 채워진 후속 요청, 후속 답변, 읽기 SHA-256과 현재 r2 정적 검사만 검토했다.

## 판정

**승인: 대표 시험 범위에서 차단·major·minor 없음.** r2에서 검증된 것은 `common-07`의 초기 요청과, 다른 새 컨텍스트가 채워진 `followup-request.txt` 및 스킬만 받고 수행한 후속 요청이다. 이는 69개 문서 프롬프트 전체의 실행이나 실제 게임 효과의 증거가 아니다.

## 시험 구분

| 시험 | 판정 | 증거 사용 범위 |
|---|---|---|
| `noncombat` r1 | 내용 제약 통과, 역사 기록 | 비전투·템포 조건이 응답에서 유지됐음을 보일 뿐, 수정 전 문구이므로 r2 실행으로 소급하지 않음 |
| `reentry` r1 | 내용 제약 통과, 역사 기록 | 고정 퀘스트·단일 배너 제약을 지킨 응답이지만 r2 조건 인계 계약의 증거로 쓰지 않음 |
| `reciprocity` r1 | 내용 제약 통과, 역사 기록 | 호혜의 양쪽 필요·유통 경계를 다룬 응답이지만 수정 전 문구이므로 r2 실행으로 소급하지 않음 |
| `reentry-r2` | 현재 r2 대표 시험 통과 | 초기 요청은 새 컨텍스트에서 수행했고, 후속 요청은 다른 새 컨텍스트가 채워진 `followup-request.txt`와 스킬만 읽고 수행함 |

## r2 재진입 시험 확인

- 초기 답변은 `적용 조건 판정`, `원서 쪽·입력·관측 근거`, `다음 확인 자료` 열을 모두 출력했다. 확정된 단일 배너·보상량·퀘스트 내용은 유지했고, 동적 이벤트·복귀 난이도 규칙·메인 정보 필드의 실제 존재는 미정 또는 미확인으로 남겼다.
- 채워진 후속 요청은 성립·불성립·미확인·해당 없음, 원서·입력·관측 근거, 다음 확인 자료를 실제 입력값으로 전달했다. 후속 읽기 기록은 이 파일과 `SKILL.md`, `s07`, `s10`만을 입력으로 남긴다.
- 후속 답변은 선행 조건 판정을 ‘유지’로 표시하고, 새 이벤트·난이도 규칙·배너 추가·퀘스트·보상 변경·지도·자동 길안내를 추가하지 않았다. 배너 정보 필드가 참조 불가하면 보완 문구를 적용하지 않는 반례를 남겼다.
- 두 답변은 실제 게임 검증을 수행했다고 주장하지 않고, 세이브 스키마·데이터 바인딩·화면·행동 로그·인터뷰를 이후 검증 자료로 남겼다.

## r1 역사 시험 확인

- `noncombat`은 전투를 추가하지 않고 외형 유료·실패 패널티·단기 미션 도입 미정을 유지했다. 단기 미션은 대기·편성에만 두고 주문 처리 중 강제 호출하지 않았으며, 시간값 대신 관측과 기호식을 사용했다.
- `reentry`은 고정 서브 퀘스트를 동적 상태처럼 초기화하지 않고 배너 하나를 유지했다. 낮은 압박 구간과 데이터 존재는 미확인으로 남기고, 실제 검증을 계획으로 표현했다.
- `reciprocity`는 신규의 클리어 도움과 숙련자의 부족한 입장 기회가 교차할 때만 호혜가 성립한다고 두었다. 장비 완전 귀속·직접 거래 금지와 시스템 재유통 미정을 구분했고, 시스템 재판매를 귀속 해제나 결제 정책으로 확대하지 않았다.

## 읽기 기록·정적 검사

- `reads.json` 네 개와 r2의 `followup-reads.json`에 기록된 파일 26개 항목을 현재 실제 파일과 SHA-256으로 대조했다. 불일치는 0건이다.
- r2 초기 읽기 기록은 `SKILL.md`, `s07`, `s10`, `ch03`, 초기 요청, 후속 템플릿을 기록한다. r2 후속 읽기 기록은 `SKILL.md`, `s07`, `s10`, 채워진 후속 요청을 기록한다.
- `static-checks.json`은 오류 0건·`verdict: pass`이며, `semantic-checks.json`은 `status: pass`, 기존 61개 ID·85개 앵커 보존, 현재 69개 ID·94개 앵커, parent/공개 링크, 조건 인계 22건을 보고한다. 이 정적 PASS는 내용·게임 효과를 증명하지 않는다는 파일의 주석도 확인했다.

## 한계와 다음 검증

이 검토는 문서의 69개 요청 모두를 실행했다는 뜻이 아니다. 실제 게임의 복귀율·심리 효과·매출·호혜 지속성도 검증하지 않았다. 이후 다른 대표 경로를 r2 문구로 실행할 때도, 채워진 후속 요청만으로 조건 판정·근거·미확인이 보존되는지를 같은 방식으로 확인한다.

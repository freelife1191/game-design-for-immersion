# README·고급 활용 가이드의 보강 조건 반영

2026-10-14 문서 보완을 완료했다. 현재 스킬·references의 19개 보강 세부 절을 기준으로 예시·산출물·검수 기준·후속 인계를 대조했다. **README와 고급 활용 가이드 두 파일만 수정**했고, 지식 스킬 34개 파일은 바이트가 동일하다.

## 결과

- README에 문제별 보강 조건과 바로 사용할 요청 경로를 추가했다. 상세 절에서 시작해 필요한 장을 보충하는 읽기 방식과, 판매 효과/가격·혜택의 다른 정책 축을 설명했다.
- 고급 가이드에 조건별 활용 표와 직접 바로가기를 추가했다. 쾌감·극단 스탯·협력 여력·제시 시점·영구 보상·재유통·호혜·소비 집단·등급 진행 조건을 산출물과 확인 문구로 반영했다.
- 기존 시나리오와 맞지 않는 조건은 원래 장르를 바꾸지 않고 별도 공통 예시로 만들었다. 비전투 경영, 심리 용어/누명/요청 순서, 고정 퀘스트 장기 복귀, 목표 없는 자유 조작의 네 예시와 전용 후속을 추가했다.
- 후속은 선행 결과의 성립·불성립·미확인·해당 없음 판정과 원서·입력·관측 근거, 다음 확인 자료를 받는다. 후속 산출물에서도 판정의 유지·변경과 근거를 남긴다.
- 협력·제시, 가치·획득, 유통·호혜의 후속은 실제 A/B 결과를 이어받도록 공개 선행 링크·제목·복사할 요청을 맞췄다.

원래 61개 요청 ID와 85개 명시 앵커는 모두 남겼다. 기존 가상 입력·확정/미정 조건·시나리오 숫자도 ID별로 보존했다. 현재 요청은 **69개**(절별 예시 36, 절별 후속 18, 공통 예시 8, 공통 후속 4, 연계 시나리오 3), 고급 가이드의 명시 앵커는 94개다.

## 조건의 실제 사용

| 조건·예외 | 예시·후속에 반영한 판단 |
|---|---|
| 쾌감의 원천·극단 스탯 | 캐릭터/플레이어 경험과 실제 효율, 레벨별 턴·피해·입력 부족 |
| 비전투 전략·단기 미션 | 구매/편성/처리의 선택과 미션의 시간·기회비용, 책의 시간 사례 비강제 |
| 분노·심리 용어·요청 순서 | 사건별 성립 조건, 책/일반 정의의 경계, 요청자의 가치·공감·거절과 조건 부족 |
| 동조·협력·제시 | 공개 판단 시점·과제 복잡도·도움 여력·비교 관계·정보 간격·고정관념 |
| 복귀·스토리 표지 | 조절 가능한 상태와 고정 콘텐츠, 신규 시스템·미확인 동선, 표지 개수 비강제 |
| 목표 없음·시연·사회적 루프 | 즉시 플레이의 충분성·시연 생략·템포 반례, 온라인 방식의 비교 |
| 저효율 보상 | 확실성·영구성·대체 가능성을 효율과 분리해 유지/수정/제거 비교 |
| 귀속·재유통·호혜 | 시스템 재판매 경로와 양쪽 부족 자원이 교차하는지 판정 |
| 상품·소비 집단·등급 | 판매 효과와 가격 조건, 해당하는 소비 집단·인구 가설, 구매 한도/진행/일일 시간 |

19개 원서 절의 매트릭스는 [독립 조건 감사](condition-audit/review.md)에 있다. 3.5.2의 표지 개수 비강제는 기존 후속에서 이미 충분했으므로 관련 원래 요청을 억지로 바꾸지 않았다.

실제 읽기 파일의 존재와 SHA-256은 [읽기 증거](trial-read-proofs.json)에 보존했다. 첫 문서 검토에서 새 후속의 조건 입력이 충분히 명시되지 않은 major와 조사 오류를 찾았다. 원래 검토와 수정 전 시험을 보존하고, 부모 산출물 → 후속 입력 → 후속 결과의 계약을 보완해 재검토했다.

[최종 문서 해시](candidate-manifest-r2.json), [전체 diff](changes.diff), [보강한 요청 목록](change-plan-applied.json)을 남겼다. 스킬과 과거 책 검수·호스트 기록은 변경하지 않았다.

69개 전체를 모델로 실행하거나 실제 게임·호스트 GUI를 시험한 기록은 아니다. 심리 효과·리텐션·매출의 실제 인과나 게임 성과는 검증 계획과 구분했다. 이번 수정 이전의 검수 통과를 새 문서 전체의 실행 증거로 재사용하지 않는다.

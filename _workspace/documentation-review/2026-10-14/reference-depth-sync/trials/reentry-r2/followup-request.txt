$game-design-for-immersion
선행 요청: common-07. 선택한 안은 A. 기존 메인 정보로 문맥을 복원하는 단일 배너다.
이어받을 결과: 현재 게임은 15분 세션의 오픈 월드이며 고정 서브 퀘스트만 있다. 2주 쉬고 돌아온 플레이어에게 메인 복귀를 UI 배너 하나로 보여 준다. 선택안 A는 기존 배너 하나에, 이미 메인 진행 정보에 있을 때만 다음 순서로 넣는다: `메인 복귀 — [직전 메인 변화] 이후 [미해결 문제]가 남았습니다. 다음: [기존 메인 목표/표지]`. 로그인 → 기존 단일 배너 → 기존 메인 목표/표지 확인만 현재 동선으로 기술한다. 지도·퀘스트 로그·자동 길안내는 존재가 확인되지 않아 가정하지 않는다. `직전 메인 변화`, `미해결 문제`, `기존 메인 목표/표지`의 저장·표시·배너 참조 가능 여부는 미확인이다.
이어받을 조건·예외: (1) 2주 이탈과 배너 1개, 보상량·퀘스트 내용·배너 개수 유지는 입력으로 성립. (2) 고정 서브 퀘스트를 동적 상태처럼 초기화하지 않으며, 동적 이벤트·복귀 난이도 규칙이 현재 존재한다고 전제하지 않는다. 실제로 조절 가능한 상태가 있을 때만 장기 이탈 뒤 재개 상태 변경이 가능하다는 책의 설명(본문 180–181쪽)에 비추어, 신규 동적 시스템 대안은 현재 불성립. (3) 배너가 세 정보를 보여 줄 수 있는지는 미확인. (4) 낮은 압박 구간, 현 배너 문구·노출 시점·닫은 뒤 화면, 메인 표지로 가는 실제 동선은 미확인이다. 근거: 입력; `s07` 본문 179–181쪽(중단/조절 가능한 상태); `s10` 본문 215–217쪽(메인 복귀의 텍스트·스토리 등 구별 표지, 표지 개수 의무 없음); 실제 게임 관측 없음. 다음에 확인할 자료: 세이브 스키마, 퀘스트 UI·배너 데이터 바인딩 사양, 현 배너 캡처와 복귀 후 화면, 15분 세션의 행동 로그·인터뷰, 난이도 파라미터/이벤트 상태 모델.
유지할 확정 정책: 보상량 유지, 퀘스트 내용 유지, UI 배너는 하나 유지, 고정 서브 퀘스트를 동적 상태처럼 초기화하지 않음.
그대로 남길 미정 사항: 동적 이벤트 도입, 복귀 난이도 규칙 도입, 배너가 `직전 변화`·`미해결 문제`·`기존 메인 목표/표지`를 참조할 수 있는지, 현재 동선의 낮은 압박 구간 존재.
새 이벤트나 난이도 규칙을 도입하지 않은 상태에서 배너 문구와 기존 정보의 연결만 보완해줘. 현재 동선에 낮은 압박 구간이 있는지 알 수 없으면 확인할 자료로 남겨줘. 배너를 늘리거나 퀘스트·보상을 바꾸지 말고, 플레이어가 직전 변화·미해결 문제·다음 행동을 읽는지 비교해줘.
산출물: 기존 배너 / 보완 문구 / 기존 정보의 근거 / 판독할 다음 행동 / 변경하지 않은 상태 / 미확인 동선 / 관찰 질문의 비교표를 작성하고, 선행 조건 판정의 유지·변경 여부와 그 근거를 적어줘.
변경한 부분과 유지한 부분을 구분하고, 실제로 검증하지 않은 내용은 검증 계획으로 표시해줘.

사용 가능한 근거 요약: `s07`은 긴 실제 중단 뒤 개방형 경험의 마음가짐이 초기화될 수 있고, 재개 상태 변경에는 동적 이벤트·확률 이벤트·난이도 규칙처럼 실제로 조절 가능한 상태가 필요하며 고정 서브 퀘스트만 있는 단순 오픈 월드에는 어렵다고 설명한다(본문 179–181쪽). `s10`은 서브 퀘스트 뒤 메인 복귀를 텍스트·스토리, 장면·스테이지, 몬스터·콘텐츠·난이도 같은 구별 가능한 표지로 알릴 수 있으나, 여러 표지를 반드시 조합해야 한다는 수량 규칙은 두지 않는다고 설명한다(본문 215–217쪽). 이는 책의 설명이며 실제 게임 검증 결과가 아니다.

# common-07 초기 검토 — 2주 후 오픈 월드 복귀

## 선택한 가상 시험안: A. 기존 메인 정보로 문맥을 복원하는 단일 배너

**새 적용안(가상 시험용 선택)**: 로그인 직후의 기존 단일 복귀 배너 하나에만, 이미 메인 진행 정보에 있는 세 항목을 순서대로 보여 준다.

> `메인 복귀 — [직전 메인 변화] 이후 [미해결 문제]가 남았습니다. 다음: [기존 메인 목표/표지]`

`[ ]` 안에는 새 퀘스트·이벤트·보상·난이도 상태를 만들지 않고, 이미 저장·표시되는 메인 진행 텍스트만 넣는다. 세 항목이 실제로 존재하고 배너에서 참조 가능한지는 아직 확인되지 않았다. 현 입력으로 확정된 것은 배너가 하나라는 사실뿐이다.

## 판단표

| 구분 | 내용 | 적용 조건 판정 | 판단 근거(원서 쪽·입력·관측) | 다음에 확인할 자료 |
|---|---|---|---|---|
| 복귀 문제 | 2주 이탈 뒤 15분 세션에 돌아온 플레이어가, 이전 메인 맥락과 바로 할 다음 행동을 읽을 단서가 부족할 수 있다. 현재 배너가 무엇을 보여 주는지는 미확인이다. | 미확인 | **입력**: 2주 뒤 복귀, UI 배너 하나. **책의 설명**: 긴 실제 중단 뒤 개방형 경험은 마음가짐이 초기화될 수 있다(본문 179–180쪽). 실제 플레이 관측은 없다. | 현 배너 문구·노출 시점·닫은 뒤 화면, 복귀 직후 행동 로그·인터뷰 |
| 현재 존재하는 상태 | 확정된 상태는 `고정 서브 퀘스트`, `메인 복귀를 보여 주는 UI 배너 1개`, `보상량 유지`, `퀘스트 내용 유지`, `배너 개수 1개 유지`다. 메인 목표명·직전 메인 변화·미해결 문제를 저장하거나 표시하는지는 알 수 없다. | 성립(확정 목록) / 미확인(메인 정보 필드) | **입력**의 확정·미정 목록. 관측 없음. | 세이브 스키마, 퀘스트 UI 사양, 현재 배너 데이터 바인딩 |
| 변경 불가 조건 | 보상량·퀘스트 내용·배너 개수는 바꾸지 않는다. 고정 서브 퀘스트를 동적 상태처럼 초기화하거나, 동적 이벤트·복귀 난이도 규칙을 이미 가진 것처럼 전제하지 않는다. | 성립 | **입력**의 명시 제한. **책의 설명**: 장기 이탈 뒤 재개 상태 변경에는 실제로 조절 가능한 동적 이벤트·확률 이벤트·난이도 규칙이 필요하며, 고정 서브 퀘스트만 있는 단순 오픈 월드에는 어렵다(본문 180–181쪽). | 없음; 구현 검토 때 변경 목록 대조 |
| 기존 구조의 개선 | 선택안 A를 적용한다. 기존 배너의 텍스트 순서만 `직전 변화 → 미해결 문제 → 기존 메인 목표/표지`로 바꾼다. 배너를 늘리지 않고, 퀘스트·보상·이벤트·난이도를 바꾸지 않는다. 이후 동선은 `로그인 → 기존 단일 배너 → 기존 메인 목표/표지 확인`으로만 기술한다. 지도·퀘스트 로그·자동 길안내의 존재는 가정하지 않는다. | 조건부 성립 | **책의 설명**: 서브 퀘스트 뒤 메인 복귀는 텍스트·스토리, 장면·스테이지, 몬스터·콘텐츠·난이도처럼 구별 가능한 표지로 알릴 수 있으며, 표지 수를 반드시 조합해야 한다는 규칙은 없다(본문 215–217쪽). **새 적용안**: 현 배너 한 개에 기존 정보를 재배열. 배너가 세 정보에 접근 가능하다는 관측은 없다. | 기존 배너가 표시할 수 있는 필드, 메인 목표를 열거나 가리키는 현재 행동, 15분 세션에서 배너 후 첫 행동 |
| 신규 시스템 대안 | 장기 이탈 뒤 감정 곡선을 재배치하려면 (a) 규칙 기반 동적 이벤트/확률 이벤트, 또는 (b) 실제 복귀 난이도 계수를 조절할 상태를 새로 설계할 수 있다. 이는 선택안 A에 포함하지 않는다. | 현재는 불성립 | **책의 설명**: 개방형 경험의 긴 공백 뒤 동적 난이도 계수를 기본값으로 되돌릴 여지가 있고, 실제 조절 가능한 상태가 있어야 한다(본문 179–181쪽). **입력**: 동적 이벤트·복귀 난이도 규칙은 미정, 서브 퀘스트는 고정. | 이벤트 상태 모델, 난이도 파라미터, 새 시스템 도입 권한·범위·테스트 계획 |
| 미정 결정 | ① 동적 이벤트 도입, ② 복귀 난이도 규칙 도입, ③ 기존 메인 정보 세 항목의 저장·표시 가능 여부가 미정이다. | 미확인 | **입력**: ①·②는 미정. 세 항목의 데이터 존재를 확인한 관측 없음. | 아래 검증 질문 및 데이터/UX 사양 |
| 필요한 관측 | 실제 시험 없이, 배너를 본 뒤 플레이어가 (1) 직전 변화, (2) 미해결 문제, (3) 다음 행동을 각각 말하거나 정확한 기존 메인 표지로 이동하는지 본다. 이탈 기간·세션 잔여 시간·현재 압박 구간도 함께 기록한다. | 미확인 | **새 검증 계획**. **책의 설명**: 중단은 경험 유형과 실제 중단 시간으로 나눠 판단하고, 복귀 뒤 내용을 설계 대상에 둔다(본문 179–180쪽). 실제 게임 검증은 수행하지 않았다. | 플레이테스트 스크립트, 행동 로그 정의, 복귀 전후 화면 녹화, 인터뷰 응답 |

## 미정 사항: 선택지·영향·검증 질문

| 미정 사항 | 선택지 | 영향 | 검증 질문 |
|---|---|---|---|
| 동적 이벤트 | 도입하지 않고 선택안 A 유지 / 별도 시스템으로 도입 | 전자는 기존 정보의 판독성만 개선한다. 후자는 장기 이탈 후 경험 순서와 사건을 바꿀 수 있으나 새 상태·규칙이 필요하다. | 현재 어떤 이벤트 상태를 저장·변경할 수 있으며, 그 변경이 15분 세션의 다음 행동을 더 명확하게 하는가? |
| 복귀 난이도 규칙 | 도입하지 않음 / 실제 난이도 계수·조절 규칙을 설계 | 전자는 난이도를 바꾸지 않는다. 후자는 난이도 상태와 초기화·적용 조건을 검증해야 한다. | 현재 조절 가능한 난이도 값이 있는가? 2주 이탈을 어떤 관측으로 판정하며, 기본값 복귀가 과도한 완화·난이도 불일치를 만들지 않는가? |
| 배너 정보원 | 기존 메인 진행 텍스트로 세 항목을 채움 / 세 항목 중 확인 가능한 정보만 표시 | 정보원이 없으면 선택안 A의 전체 문구는 쓸 수 없다. 없는 정보를 새 상태로 만들어 채우지 않는다. | 세이브와 현재 UI에 `직전 변화`, `미해결 문제`, `기존 메인 목표/표지`가 각각 존재하는가? |

## 근거의 구분과 실제 읽은 자료

- **책의 설명**: 실제 중단과 경험 중단의 구분, 조절 가능한 상태가 있어야 하는 장기 이탈 재개, 서브 퀘스트 뒤 메인 복귀 표지의 유형은 `s07` 본문 179–181쪽과 `s10` 본문 215–217쪽에 근거한다.
- **사례 재구성**: 없다. 책의 ARPG·다른 게임 사례를 이 프로젝트의 사실로 옮기지 않았다.
- **새 제안**: 선택안 A의 단일 배너 문구 순서와 관찰 계획이다. 실제 게임에서 효과를 검증하지 않았다.

# 2주 이탈 뒤 메인 복귀 배너 보완안

## 판정

선행 조건의 판정은 **유지**한다. 이번 보완안은 새 이벤트나 복귀 난이도 규칙을 만들지 않고, 기존의 단일 배너가 이미 가진 메인 진행 정보를 읽을 수 있을 때 그 정보를 한 문장 안에서 연결하는 안이다. `s07`은 장기 이탈 뒤 재개 상태를 바꾸려면 실제로 조절 가능한 동적 이벤트·확률 이벤트·난이도 규칙이 있어야 하며, 고정 서브 퀘스트만 있는 단순 오픈 월드에는 어렵다고 한정한다(본문 180–181쪽). 따라서 그와 같은 새 시스템은 현재 조건에서 도입하지 않는다.

`s10`은 서브 퀘스트 뒤 메인 복귀를 텍스트·스토리 또는 다른 구별 표지로 알릴 수 있다고 설명하며, 표지를 여러 개 조합해야 한다는 수량 규칙은 두지 않는다(본문 215–217쪽). 그러므로 배너 하나를 유지하는 것은 이 근거와 충돌하지 않는다. 이는 책의 설명에 따른 설계 판단이며, 실제 게임에서 검증한 결과가 아니다.

## 변경과 유지

**변경안**은 배너가 세 정보에 접근 가능한 경우에 한해, 기존 메인 진행 정보를 `직전 변화 → 미해결 문제 → 다음 행동` 순서로 한 문장에 연결하는 표시 규칙이다. 이 규칙은 별도 배너·이벤트·길안내를 추가하지 않는다.

**유지**하는 정책은 보상량, 퀘스트 내용, 단일 UI 배너, 고정 서브 퀘스트를 동적 상태처럼 초기화하지 않는다는 점이다. 동적 이벤트 도입과 복귀 난이도 규칙 도입도 미정으로 유지하며, 현재 존재한다고 전제하지 않는다.

## 검증 계획 — 아직 실제 검증하지 않음

1. 세이브 스키마와 퀘스트 UI·배너 데이터 바인딩 사양에서 세 필드의 저장·표시·참조 가능 여부를 확인한다. 세 필드가 모두 확인될 때만 보완 문구를 구현 대상으로 확정한다.
2. 현 배너 캡처와 로그인 뒤·배너를 닫은 뒤 화면을 확인해, 실제 노출 시점과 기존 메인 목표/표지로 가는 동선을 기록한다. 낮은 압박 구간의 존재도 이 자료와 15분 세션의 행동 로그·인터뷰로 확인한다. 확인 전에는 그 구간이 있다고 판단하지 않는다.
3. 2주 이탈 뒤 복귀한 플레이어 관찰에서 `직전 메인 변화`, `미해결 문제`, `다음 행동`을 각각 말로 재확인하게 한다. 배너를 본 뒤 기존 메인 목표/표지를 확인하는 실제 행동이 가능한지와, 배너를 닫은 뒤 막히는 지점을 기록한다.
4. 난이도 파라미터·이벤트 상태 모델은 새 복귀 규칙을 설계하기 위한 전제가 아니라, 현재 조절 가능한 상태가 실제로 있는지 구분하기 위한 확인 자료로만 검토한다.

위 검증은 실제 게임을 이미 검증했다는 뜻이 아니다. 현재 확정된 사실은 15분 세션의 오픈 월드, 고정 서브 퀘스트, 2주 이탈 뒤 단일 배너, 그리고 보상·퀘스트·배너 수를 유지한다는 조건뿐이다.

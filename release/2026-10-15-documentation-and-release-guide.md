# 문서 구성과 릴리스 노트 가이드

> 작성일: 2026-10-15 KST<br>
> 대상: 스킬 사용자와 릴리스를 준비하는 유지보수자

## 변경 사항

- README와 사용자 가이드의 시작점, 문서 간 이동 경로, 긴 고급 활용 문서의 목차를 정리했습니다.
- 릴리스 노트의 파일 규칙과 GitHub Release 생성 절차를 추가했습니다.

## 영향과 다음 행동

- 스킬 호출 방식과 지식 자료의 내용은 바뀌지 않았습니다.
- 공개 릴리스가 필요하면 [릴리스 가이드](https://github.com/freelife1191/game-design-for-immersion/blob/main/release/README.md)의 명령에서 태그, 전체 커밋 SHA, 제목, 파일명을 실제 값으로 바꿔 초안을 만들고 검토한 뒤 공개합니다.

## 검증 범위

- 문서 경로와 Markdown 앵커를 정적으로 점검했습니다.
- 전체 호스트에서 스킬을 실제로 호출하거나 게임 플레이를 실행한 결과는 이 노트에 포함하지 않습니다.

# 몰입 설계 판단표

책의 판단 기준을 실무용 규칙으로 재구성했다. 고정 수치보다 플레이어·진행 단계·목표 경험의 조건을 먼저 확인한다.

| 발견한 상황 | 우선 할 일 | 이유 · 참조 |
|---|---|---|
| ‘재미없다’ 외에 문제를 설명하기 어렵다 | 기대한 감정, 실제 감정, 그 감정을 만든 행동을 적는다 | 콘텐츠보다 경험을 기준으로 진단 · s03, s06 |
| 조작 실패가 많다 | 거리·시간·정확도·빈도를 분리하고 원인을 관찰한다 | 지각 실패와 능력 한계 초과는 처방이 다름 · s01 |
| 난이도를 계속 올렸는데 이탈한다 | 한계 도달 후 변동·회복·성장 체감 구간을 넣는다 | 상승만으로는 한계 이후의 몰입을 유지하기 어려움 · s01 |
| 항상 같은 선택이 최선이다 | 정보·비용·상성·행동 순서·자원 제약을 바꿔 상황별 유효성을 비교한다 | 선택 수보다 선택 간 관계가 전략을 만듦 · s02 |
| 슬픔·공포 장면이 컷신에서 끝난다 | 상실·통제력·관계를 플레이어의 행동 결과로 연결한다 | 직접 경험하는 감정의 원인이 필요 · s03 |
| 친구·채팅은 있는데 관계가 약하다 | 공통 목표 아래 서로의 기여가 상대 상황을 바꾸게 한다 | 기능보다 공통 경험이 관계를 연결 · s05 |
| 강한 장면은 많지만 기억에 남지 않는다 | 자극의 순서·지속 시간·대비·해소를 곡선으로 본다 | 같은 자극의 누적은 감정의 변화와 다름 · s06–09 |
| 매일 반복하는 경험을 구성한다 | 일정 규모의 작은 절정을 반복하는 파동형을 검토한다 | 반복 가능한 해소가 필요 · s07 |
| 마지막에 가장 큰 해소가 필요하다 | 준비 후 폭발이면 기본형, 점차 커지는 파동이면 할리우드형 | 목표 감정 흐름에 따라 선택 · s07 |
| 성장 수치는 늘지만 성취감이 약하다 | 총 능력과 직전 단계 대비 증가량을 함께 그리고 주요 해금 시점을 확인한다 | 여러 경로의 중첩이 봉우리를 평탄하게 할 수 있음 · s11 |
| 희귀 보상이 별로 중요하지 않다 | 효용·절박성·획득 난이도·외부 인정을 점검한다 | 희귀함 하나만으로 가치가 정해지지 않음 · s12 |
| 거래 가능 여부를 정해야 한다 | 공급·소비·가격과 소과금/비과금의 역할을 함께 비교한다 | 유통 규칙이 경제와 사회 관계를 바꿈 · s14 |
| 과금 계층이 같은 구간에 모두 막힌다 | 계층별 능력·스테이지 난이도·콘텐츠 소모 속도를 함께 본다 | 금액에 따른 진행 경험이 다름 · s15, s16 |
| 경제 경로 하나만 지나치게 효율적이다 | 전체 능력 비중, 시간·금액 소비, 공급을 다시 배분한다 | 경로별 수치보다 전체 계획이 중요 · s18 |

## 곡선 선택과 수치 점검

- **단일 경험의 감정 흐름** → 기본형 / 할리우드형 / 파동형 중 선택한다. ‘몰입’ 하나의 수치로 모든 감정을 대신하지 않는다.
- **기조** → 가벼움/무거움과 느림/빠름을 따로 정한다. 강도와 속도를 같은 축으로 취급하지 않는다.
- **성장** → 실력 향상 / 기능 해금 / 수치 증가를 구분한다. 제4장의 ‘성장 곡선’은 주로 수치 성장이다.
- **F2P 경제** → 목표 진행 → 능력 비중 → 소비량 → 생산량을 연결한다. 장기 거래·공급과 전체 예산도 확인한다.
- **숫자 기본값** → 이 책에는 모든 게임에 통용되는 통과율·과금액·만렙 일수가 없다. 표의 비율과 RMB 금액, 55일 만렙 등은 해당 예시의 조건이다.

## 빠른 경고 신호

콘텐츠만 늘린다 → 전체 감정 곡선을 확인한다. 성장 경로만 늘린다 → 합계와 변화량을 확인한다. 채팅만 추가한다 → 상호 기여를 확인한다. 강한 보상만 추가한다 → 가치와 기대를 확인한다. 원문 사례의 숫자를 그대로 쓴다 → 현재 프로젝트의 조건을 먼저 확인한다.
